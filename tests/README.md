# 测试索引

## Next.js 业务测试

`*.test.ts` 使用 Vitest，覆盖日期窗口、指标计算、筛选、仓库查询、开发验收数据和 Excel 工作簿。

```bash
pnpm test
```

## 数据同步测试

`test_*.py` 使用 Python `unittest`，覆盖工单分页和变更、完整规格匹配、销售行去重、发货与仓库证据、采集覆盖及发布失败门槛。Vitest 另覆盖规则编辑和批次指针的事务一致性。

```bash
pnpm test:data
```

提交或发布前使用 `pnpm verify` 统一执行静态检查、两套测试和生产构建。

这些隔离单元测试不替代正式数据库 SQL、真实数据对账、员工入口和 Excel 验收。测试样本只存在于测试代码，不能导入生产表。
