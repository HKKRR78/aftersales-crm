# CRM 售后 Dashboard 数据口径

## 时间周期

- 一周按周日到周六。
- 示例：`2026-07-19` 到 `2026-07-25` 显示为 `0719-0725`。
- Dashboard 默认展示近 5 个完整周。
- 页面可切换“本周同进度”，按本周已结束自然日对比上周相同星期范围。
- 日更脚本滚动同步近 8 周班牛售后，以处理售后工单滞后创建/更新。

### 本周同进度

- 今天尚未结束的数据不参与计算；星期日显示“本周尚无完整日”。
- 本周和上周不仅日期范围相同，售后工单观察时间也相同。
- 售后问题必须同时满足订单付款时间位于周期内，且 `api_created_at` 早于该周期截止时间。
- `api_created_at` 为空的记录从同进度指标中排除并单独提示数量。
- 本周同进度属于早期暴露预警，不等同于最终完整周售后率。

## 售后问题数

主来源：`ods_banniu_aftersales` 中 `source_file_name=banniu_api` 的记录。

去重口径：

```text
班牛 task_id + 商品行 child_key
```

落库唯一键：`aftersales_business_key`。

## 订单分母

主来源：`ods_wdt_stock_out`。

订单分母按付款时间统计，按 `origin_order_no` 去重。

为了页面速度，日更生成周汇总表 `dws_crm_order_weekly` 和日汇总表 `dws_crm_order_daily`。日汇总滚动刷新最近 70 天，用于任意同进度日期范围求和。

汇总粒度：

- `total / __all__`：全店总订单分母
- `merchant_code / 商品编码`：商品分母
- `warehouse / WDT仓库名`：仓库分母

## 售后率

```text
售后率 = 售后问题数 / 订单分母
```

页面显示百分比。

仓库问题视图只统计一级问题为 `库房问题` 的记录：

```text
仓库库房问题率 = 库房问题数 / 对应 WDT 仓库订单数
```

仓库完整周、同进度、Dashboard 仓库概览和仓库导出均使用这一口径。仓库未映射或对应订单分母不存在时显示“分母不可用”，不使用全店订单兜底。商品编码未匹配时同样不使用全店订单兜底。

## 环比

```text
环比 = (当周售后率 - 上周售后率) / 上周售后率
```

如果上周售后率为 0、本周大于 0，显示 `上期为0`。

同进度视图还显示售后率变化百分点、相对变化、预计问题数和超预期问题数。初始红色预警条件为超预期问题数不少于 3 且售后率上升不少于 0.3 个百分点，阈值由运行环境配置。

## 颜色规则

- 红色：当期售后率 >= 2%
- 黄色：环比售后率增长
- 深红色：同时命中红色和黄色

## 仓库映射

班牛返回的是仓库编码，例如 `QHC`。WDT 订单表使用仓库名称，例如 `启航仓`。

映射表：`dim_crm_warehouse_map`。

自动推断逻辑：

1. 用班牛售后记录的订单号/运单号关联 WDT 出库明细。
2. 对同一个班牛仓库编码，统计匹配到的 WDT 仓库名次数。
3. 取匹配次数最高的仓库名作为映射。
4. `source=manual` 的人工映射不会被日更覆盖。

## 已知口径风险

- 班牛商家编码可能是组合编码，例如 `A+B`；当前会尝试按 `+` 拆分匹配 WDT 商品编码，但仍可能出现订单分母为 0。
- 班牛售后有滞后创建/更新，因此历史完整周的售后数可能在后续几天变化。
- 仓库低频编码映射置信度可能不高，建议定期抽查 `confidence` 较低的映射。

## 班牛分页完整性

同步脚本读取 `task.list.new` 返回的 `total` 和 `total_page_num`，以第一页最大任务 ID 固定本轮快照上界，并按接口报告的动态总页数完整分页。分页过程中新增且大于快照上界的任务留到下一轮；本轮快照唯一任务数与第一页总数不一致时任务失败，不再把截断结果当作成功。
