# CRM 周对比双视图上线说明

## 页面入口

- 完整周趋势：`/crm/dashboard?period=closed`
- 本周同进度：`/crm/dashboard?period=progress`

不传或传入未知 `period` 时使用 `closed`。明细、商品、仓库、筛选及导出均保留该参数。

## 数据链路

```text
ods_wdt_stock_out
  -> scripts/crm_order_daily_refresh.py
  -> dws_crm_order_daily（最近 70 天）

ods_banniu_aftersales
  -> wdt_pay_time 限制订单周期
  -> api_created_at 限制观察截止时间
  -> 本周 / 上周同进度指标
```

本周同进度只统计今天零点前已经结束的自然日。星期日不计算同进度指标。订单分母为 0 时页面显示“分母不可用”。

## 预警配置

- `CRM_PROGRESS_ALERT_MIN_EXCESS`：红色预警最少超预期问题数，默认 `3`
- `CRM_PROGRESS_ALERT_MIN_DELTA_PP`：红色预警最少上升百分点，默认 `0.3`

## 部署顺序

1. 备份候选代码、数据库表结构和 Nginx 配置。
2. 同步代码到 `/Users/Shared/ecom-profit/projects/crm-canary`。
3. 执行 `scripts/crm_order_daily_refresh.py --days 70`，创建并回算日汇总。
4. 执行班牛同步脚本的 schema 初始化，补充 `idx_crm_progress` 索引。
5. 重启候选后端 18089，不修改稳定后端 18088。
6. 使用灰度 Cookie 验证两个视图和四类 Excel。

## 回滚

将 Nginx 流量保持或切回稳定后端 18088。新增日汇总表及索引不影响旧代码，可以保留；候选代码从部署备份恢复后重启 18089。
